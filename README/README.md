## What am I going to build?

I am going to build an NLP (natural language processing) anomaly detection system that examines SSH logs for anything suspicious.

### Why do I want to make this?

I want to make this because my interest lies in cybersecurity and ML. This project combines both fields, and I think it would be interesting to learn more about it and perhaps turn it into my work later on.

## Preconditions

This project uses real SSH logs, so I need to take AVG regulations into account since I see IP addresses.
I will mask the IP addresses or partially obscure them, so that the anomaly remains visible without showing a traceable address.

### Societal impact

That intrusion attempts are detected more quickly, so action can be taken sooner to protect other people's data. The risk is that this is an AI model, and such models can make mistakes. These mistakes can be false positives and missed detections (false negatives).

### Legal impact

For this school project, the GDPR is the most important legal framework, because of the IP addresses in the log data.
