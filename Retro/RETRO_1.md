## Is het gelukt om de leerdoelen voor dit project waar te maken?

Het is gedeeltelijk gelukt. Ik heb geleerd wat TF-IDF is: Term Frequency-Inverse Document Frequency. TF (Term Frequency) meet hoe vaak een woord voorkomt in een document. Hoe vaker het voorkomt hoe betekent vaak dat het belangrijker is. Het is waarschijnlijk relevant voor de comtext van het document. IDF ( Inverse Document Frequency) Vermindert het gewicht van veelvoorkomende worden over verschillende documenten en verhoogdt het gewicht van zeldzaame worden.

Ook heb ik leren werken met het Isolation Forest Model. Wat is Isolation Forest? Het is een populair model die vaak gebruikt wordt in: cybersecurity, finance, gezondheids zorg en manufacturing. Het werkt door het isoleren van data punten die afwijken van de rest door random patronen.

Leren hoe ik een model kan trainen daar ben ik nog mee bezig.
